# 基于主成分分析的总和生育率影响因素分析

[![R](https://img.shields.io/badge/R-4.2-blue)](https://www.r-project.org/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

## 📌 项目简介

本项目利用 **2010-2021 年中国宏观统计数据**，通过**主成分分析（PCA）** 和**主成分回归**，系统研究了影响总和生育率（Total Fertility Rate, TFR）的关键因素。

## 🎯 研究背景与意义

中国总和生育率自 1980 年代以来总体呈波动下降趋势。2020 年已跌破 1.3，远低于 1.8 的警戒线；2022 年人口自然增长率首次转负。低生育率将导致人口老龄化、劳动力短缺、社会创新活力下降等问题。因此，分析生育率低的原因并预测其走向具有重要现实意义。

## 📊 数据来源与变量

- **时间范围**：2010–2021 年（12 个年度观测）
- **数据来源**：国家统计局、联合国人口司、民政统计年鉴
- **样本量**：20 个变量（1 个因变量 + 18 个自变量 + 1 个年份）

**变量列表**（所有变量均有完整中文注释）：

| 类别 | 变量名称（缩写） | 说明 |
| :--- | :--- | :--- |
| **因变量** | TFR | 总和生育率 |
| **经济因素** | PCDIR, GINI, PCCER, ENGEL, GDP, GDPI | 人均可支配收入、基尼系数、人均消费、恩格尔系数、GDP、GDP指数 |
| **人口因素** | WEL, CHU, UZR, CDR, ODR, IMR | 女性受教育程度、初婚率、城镇化率、少儿/老年抚养比、婴儿死亡率 |
| **社会因素** | ADR, NEI, MI, UPR, PI, CASE | 房价、养老保险、生育保险、失业率、CPI、婚姻家庭案件数 |

> 所有原始数据均通过国家统计局官方发布数据整理计算，详见 `data/fertility_data.csv`。

## 🔬 研究方法与步骤

1. **数据预处理**  
   - 计算结婚率、初婚率、城镇化率等衍生指标  
   - 对女性受教育程度抽样数据使用中位数填补缺失值  
   - 所有处理逻辑见 `scripts/01_data_preparation.R`

2. **描述性统计分析**  
   - 绘制 TFR 时序图、收入与消费对比图等

3. **主成分分析（PCA）**  
   - Bartlett 球形检验（p < 0.01，变量间高度相关，适合 PCA）  
   - 按特征值 > 1 选取主成分  
   - 前三个主成分累计解释 **94.66%** 的方差

4. **主成分回归**  
   - 以标准化后的 TFR 为因变量，PC1、PC2、PC3 为自变量建立线性回归模型

5. **模型诊断**  
   - 拟合优度（R²）、F 检验、t 检验  
   - 残差正态性（Q-Q 图）  
   - Durbin-Watson 检验（自相关）  
   - Breusch-Pagan 检验（异方差）

## 📈 主要结果

### 主成分解释

| 主成分 | 方差贡献率 | 累计贡献率 | 含义概括 |
| :--- | :--- | :--- | :--- |
| PC1 | 78.10% | 78.10% | 社会经济综合发展指标（收入、消费、房价、抚养比等） |
| PC2 | 10.78% | 88.88% | 婚姻法律环境（恩格尔系数、失业率、婚姻案件数） |
| PC3 | 5.78% | 94.66% | 教育公平程度（基尼系数、女性受教育程度、GDP指数） |

### 回归模型诊断

| 指标 | 数值 | 说明 |
| :--- | :--- | :--- |
| R² | **0.8643** | 模型解释了 86.4% 的 TFR 变异 |
| 调整后 R² | **0.8134** | 考虑变量个数后的拟合度 |
| F 检验 p 值 | **0.001** | 模型整体显著 |
| Durbin-Watson p 值 | 0.4198 (>0.05) | 残差无自相关 |
| Breusch-Pagan p 值 | 0.7075 (>0.05) | 残差无异方差 |

### 关键结论

- **初婚率下降、少儿抚养比与老年抚养比上升** 是生育率下降的**直接相关因素**。
- 经济发展（收入、房价增长）和社会保障完善在一定程度上降低了生育意愿。
- 女性受教育程度提高、婚姻案件增多等社会文化因素也有显著影响。
