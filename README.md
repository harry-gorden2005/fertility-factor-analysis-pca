# 基于主成分分析的总和生育率影响因素分析

## 📌 项目简介

本项目利用2010-2021年中国宏观统计数据，通过**主成分分析（PCA）** 和**主成分回归**，研究影响总和生育率（Total Fertility Rate, TFR）的关键因素。

## 🎯 研究背景

中国总和生育率自1980年代以来总体呈波动下降趋势。2020年已跌破1.3，远低于1.8的警戒线；2022年人口自然增长率首次转负。低生育率将导致人口老龄化、劳动力短缺、社会创新活力下降等问题。因此，分析生育率低的原因并预测其走向具有重要现实意义。

## 📊 数据来源

- **时间范围**：2010-2021年
- **数据来源**：国家统计局、联合国人口司、民政统计年鉴
- **样本量**：12年 × 18个变量

**变量列表**：

| 类别 | 变量名称（缩写） |
| 因变量 | 总和生育率 (TFR) |
| 经济因素 | 人均可支配收入(PCDIR)、基尼系数(GINI)、人均消费支出(PCCER)、恩格尔系数(ENGEL)、GDP(GDP)、GDP指数(GDPI) |
| 人口因素 | 女性受教育程度(WEL)、初婚率(CHU)、城镇化率(UZR)、少儿抚养比(CDR)、老年抚养比(ODR)、婴儿死亡率(IMR) |
| 社会因素 | 房价(ADR)、养老保险参保人数(NEI)、生育保险(MI)、失业率(UPR)、消费价格指数(PI)、婚姻家庭案件数(CASE) |

## 🔬 研究方法

1. **描述性统计分析**：绘制各变量时序图
2. **相关性检验**：Bartlett球形检验（p < 0.01，适合PCA）
3. **主成分分析（PCA）**：降维提取综合指标
4. **主成分回归**：建立TFR与主成分的线性模型
5. **模型诊断**：R²、F检验、t检验、DW检验（自相关）、BP检验（异方差）、残差正态性检验

## 📈 主要结果

- **前3个主成分累计解释94.6%的方差**
  - PC1（78.0%）：社会经济综合指标（收入、消费、房价、抚养比等）
  - PC2（10.8%）：婚姻法律环境（恩格尔系数、失业率、婚姻案件数）
  - PC3（5.8%）：教育公平程度（基尼系数、女性受教育程度、GDP指数）

- **回归模型**：R² = 0.8557，调整R² = 0.8015，F检验p = 0.001

- **模型诊断通过**：
  - 残差正态性（Q-Q图直线）
  - 无自相关（DW = 1.90）
  - 无异方差（BP检验p = 0.6756）

## 💡 结论与建议

- 初婚率下降、少儿/老年抚养比上升是生育率下降的**直接相关因素**
- 建议加强网络婚育观引导、完善养老保障、创造更多就业机会、缓解收入分配不均
